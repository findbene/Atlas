Approved Phase 18 scope:
Add a rule-based “Start Here” learner path on course/project browsing surfaces.

Goal:
Help learners know the best first project to start with in each course, using trusted difficulty labels and existing visible project data.

Core behavior:

1. For courses with at least one beginner project:

   * Show a “Start Here” recommendation using the best beginner project.
   * Prefer beginner projects whose slug/title clearly indicates beginner/foundations.
   * Then tie-break by estimated duration, step count, and stable slug ordering.

2. For courses with no beginner project:

   * Do not pretend there is a beginner project.
   * Show a fallback recommendation labeled something like:
     “Most approachable project available”
   * Include honest copy:
     “Beginner projects for this course are coming soon. This is the gentlest available starting point for now.”
   * Do not label advanced-only courses as beginner-friendly.

3. Do not expose internal anchor metadata publicly.

4. Anchors should not be called anchors in the UI.

5. Do not mutate DB.

6. Do not author projects.

7. Do not change difficulty labels.

T001 — Implement Start Here recommendation helper
Create a small deterministic helper for selecting the recommended first project from a course’s visible projects.

Suggested rule:

1. Rank difficulty:

   * beginner first
   * intermediate second
   * advanced third
2. Within beginner:

   * prefer slug/title containing beginner, foundations, essentials, intro, or getting-started
3. Then tie-break:

   * lower estimated duration
   * fewer steps
   * stable slug/title order

Return:

* recommended project
* recommendation type:

  * start_here
  * most_approachable_available
* reason/copy key:

  * beginner_available
  * no_beginner_available
* whether the course has any beginner project

Requirements:

* Pure function if possible.
* Easy to test.
* No DB writes.
* No mapToCourse.
* No AI recommendation logic.
* No new schema.
