PHASE 32 — Project Learning Experience Architecture:
Guided / Hint-Based / Independent / Adaptive Mode System

Goal:
Design and implement the core learner journey before scaling the project catalog.

The learner should be able to complete each project in one of four modes:

1. Guided Mode
- full step-by-step support
- more explicit instructions
- stronger explanations
- lower frustration for beginners

2. Hint-Based Mode
- learner attempts first
- hints unlock progressively
- hints should follow a ladder:
  - conceptual nudge
  - technical clue
  - partial structure
  - near-solution explanation

3. Independent Mode
- minimal instruction
- stronger validation emphasis
- portfolio/recruiter-grade expectation
- no early solution leakage

4. Adaptive “Choose for Me” Mode
- platform recommends the best mode using learner performance signals:
  - prior completions
  - failed attempts
  - validation errors
  - hints used
  - time spent
  - skill confidence
  - repeated weak areas
