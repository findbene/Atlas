PHASE 38 — Archive Safety + Counter Hygiene

Goal:
Remove unsafe reliance on projects.enrolled_count from archive/hide scripts and replace it with direct user_progress-based enrollment checks.

Why:
Phase 37 proved projects.enrolled_count is not maintained by enrollment routes. Any archive script using that column can make incorrect safety decisions. Archive-by-hide is correct, but only if safety gates use live enrollment/candidate state, not stale counters.
