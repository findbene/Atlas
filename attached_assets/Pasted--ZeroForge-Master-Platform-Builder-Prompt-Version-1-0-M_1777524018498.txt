## SECTION 0 — PRIME DIRECTIVE

You are building **ZeroForge** [CUSTOMIZE: rename if desired], a next-generation technical learning platform for Data Engineering, AI Engineering, Data Science, and MLOps. The platform's core philosophy is **project-first, production-grade, zero-to-hero learning**.

The MVP launches with one fully built domain: **Data Engineering**. The other three domains (AI Engineering, Data Science, MLOps) must appear in the navigation and marketing pages as "Coming Soon" with an email waitlist capture — but they are NOT built out yet.

This is not a video course platform. It is a **project-based, in-browser coding platform** with a built-in AI tutor, live Python/SQL editors, step-by-step guided workflows, and a curriculum engineered for what **2026 and beyond hiring managers actually want to see** from candidates.

Build a production-quality MVP. No scaffolding. No placeholder pages. No fake data beyond seeded demo content. Every feature you build must work end-to-end.

## SECTION 1 — TECH STACK

### Frontend
- **Framework**: Next.js 14+ with App Router, TypeScript strict mode
- **Styling**: Tailwind CSS + shadcn/ui component library
- **State Management**: Zustand (global client state) + TanStack Query v5 (server state, caching)
- **Code Editor**: Monaco Editor (same engine as VS Code) — use `@monaco-editor/react`
- **Icons**: Lucide React
- **Animations**: Framer Motion (use sparingly — only for meaningful transitions)
- **Charts/Progress**: Recharts for progress visualizations

### Backend
- **API Layer**: Next.js API Routes (full-stack, no separate backend service for MVP)
- **Runtime**: Node.js 20+
- **Validation**: Zod for all API inputs and outputs

### Database
- **Primary DB**: PostgreSQL via **Neon** (serverless PostgreSQL, Replit-compatible) or **Supabase**
- **ORM**: Drizzle ORM (type-safe, fast, Neon-compatible)
- **Migrations**: Drizzle Kit

### Authentication
- **Auth Provider**: **Clerk** (best for Replit deployment — handles OAuth, session management, and webhooks cleanly)
- Support: Google OAuth, GitHub OAuth, Email/Password

### Code Execution
- **Python Execution**: **Piston API** (open-source, free, supports Python 3.11+) — self-hostable on Replit; fallback to Judge0 RapidAPI free tier
- **SQL Execution**: **DuckDB WASM** (in-browser SQL execution, zero-latency, no server round-trip for basic SQL) + server-side PostgreSQL connection for advanced project exercises that need a real Postgres environment
- Both editors must support: syntax highlighting, auto-complete basics, error underlining, line numbers, copy code button, reset to starter code button

### AI Tutor
- **Provider**: Anthropic Claude API (`claude-sonnet-4-6` model)
- **Streaming**: Use Anthropic's streaming API for real-time token-by-token output in the tutor chat
- **Context window**: Include system prompt with current project context, current step, user's current code, learning mode, and conversation history (last 10 messages)
- Store API key in environment variable `ANTHROPIC_API_KEY`

### Payments & Subscriptions
- **Provider**: Stripe
- **Subscription Products**:
  - Free Tier (no payment required)
  - Pro Monthly: $29/month
  - Pro Annual: $199/year
- Use Stripe Checkout for payment flow
- Use Stripe Webhooks to sync subscription status to the database
- Store Stripe keys in environment variables

### Storage
- **Media/Images**: Cloudflare R2 (or Supabase Storage) for project thumbnails, note images
- **Videos**: YouTube embed (for MVP — no custom video hosting)

### Other
- **Email**: Resend (for welcome emails, certificate delivery, waitlist confirmations)
- **Cache**: Upstash Redis for rate-limiting AI tutor calls per user per day
- **Environment**: All secrets in `.env.local`, never hardcoded

#### LEFT PANEL — TABS

**Tab 1: Instructions**
- Step title (h3)
- Full step instructions rendered as markdown (with syntax-highlighted code blocks)
- "Expected output" section with a code block showing what correct output looks like
- For **Guided Mode**: Show full step instructions immediately
- For **Hint Mode**: Show the challenge description only. Show a "Need a hint?" section with 3 progressive hint buttons. Clicking Hint 1 reveals it; Hint 2 is locked until Hint 1 is seen; Hint 3 locks until Hint 2 seen.
- For **Independent Mode**: Show only the project brief and final deliverable requirements. No step-by-step, no hints visible.
- **Reveal Answer button** (always present, regardless of mode):
  - Styled as `text-red-400 border-red-800` — not prominent but accessible
  - Click triggers a confirmation modal: `"Are you sure? Revealing the answer will be logged and won't count toward your completion streak. You can still complete the project after viewing it."`

**Tab 3: AI Tutor**
- A full chat interface powered by the Anthropic Claude API (streaming)
- System prompt structure (build this exactly):

```
CURRENT CONTEXT:
- Platform: ZeroForge — a data engineering learning platform
- Project: {project.title}
- Track: {track.title} ({track.difficultyLevel})
- Current Step: {currentStep.stepNumber} of {project.totalSteps}: "{currentStep.title}"

{userCurrentCode}
\`\`\`

STEP INSTRUCTIONS:
{currentStep.instructionMd}

- Always be encouraging, patient, and technically precise.
- If the user's code has a bug, diagnose it clearly but don't just hand over the fix unless mode allows it.
- Format code with proper markdown fenced code blocks.

```

## SECTION 10 — COMPETITIVE DIFFERENTIATORS TO IMPLEMENT

Based on analysis of: Analyst Builder, ProjectPro, DataExpert.io, DataCamp, Educative.io, DataQuest, HyperSkill, Zero to Mastery, PluralSight, CodeCademy.

**Steal from Analyst Builder**: Real databases in the SQL editor. Don't use fake/toy data — use realistic, industry-representative datasets seeded in DuckDB and PostgreSQL.

**Steal from DataExpert.io**: Technical depth and credibility. Don't dumb down the curriculum. Projects must use real tools, real configurations, and produce outputs that look like real production work.

**Steal from DataCamp**: Interactive in-browser execution with zero setup. The moment a user signs up they are coding — no downloads, no environment setup. Also steal their Skill Track and Career Track visual organization.

**Steal from Educative.io**: The text + code hybrid reading experience. Notes should be rich, structured prose with inline code examples — not a wall of video timestamps.

**Steal from DataQuest**: The "guided answer checking" — after each step, show whether the user's output matches the expected output (exact match or structural match). Green check = correct, red X = try again.

**Steal from HyperSkill**: Theory → Practice immediately — every theory note has a "Try it now" button that drops the user into a micro-exercise right in the same page.

**Steal from Zero to Mastery**: Community and career framing. Add a "Why this matters for hiring" section to every project card (1–2 sentences explaining what this skill signals to a hiring manager).

**Steal from CodeCademy**: XP system and daily streak. Award XP for completing steps, projects, and streaks. Show an XP level and progress bar in the dashboard.

**From ProjectPro.io**: Every advanced project should include a "Real-World Context" section explaining what company or industry scenario this is based on (anonymized/generic is fine).

**Unique to ZeroForge (no one else does this)**: The three-mode learning system (Guided / Hint / Independent) within the SAME project. Every platform picks one mode. ZeroForge lets the learner choose, and lets them switch mid-project. This is the headline differentiator. Lead with it everywhere.
